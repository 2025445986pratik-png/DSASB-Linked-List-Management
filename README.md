# Linked List Management System in Java

## Project Overview
This project is a menu-driven Java console application that demonstrates the implementation and operations of Singly Linked Lists and Doubly Linked Lists.

The linked lists are implemented manually using nodes and pointers (references), without using Java's built-in `LinkedList` class.

## Technologies Used
- Java
- JDK 16
- IntelliJ IDEA Community Edition

## Features

### Singly Linked List
- Insert at the beginning, end, and a specified position
- Insert before or after a given value
- Delete from the beginning, end, a specified position, or by value
- Search and update elements
- Display the list
- Count nodes
- Find maximum and minimum values
- Find the middle node
- Reverse and sort the list
- Remove duplicate values

### Doubly Linked List
- Supports the same insertion, deletion, search, and update operations
- Display the list in forward and backward directions
- Count nodes
- Find maximum and minimum values
- Find the middle node
- Reverse and sort the list
- Remove duplicate values

### Comparison
The application also provides a menu to compare Singly Linked Lists and Doubly Linked Lists.

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure JDK 16 is configured.
3. Open `Main.java`.
4. Click the Run button.
5. Use the console menu to select a linked list and perform operations.

## Learning Objectives
- Understand node-based data structures.
- Learn insertion and deletion operations.
- Understand references between nodes.
- Compare singly and doubly linked lists.
- Practice Java classes, methods, loops, and conditional statements.
